Pokédex Race

A small Pokédex that sends several API requests per selection, some waiting on earlier answers and some running together. Pick one Pokémon, then another before the first finishes, and compare what each version shows.

broken

Broken version

Draws every answer the moment it arrives, so a slow, old answer can land on the new Pokémon's card.

 fixed

Fixed version

Gives each click a ticket number and ignores answers from older tickets.

Try the race

  • Click an empty part of the page and press R: it picks Eevee, then Gholdengo 50 ms later.
  • To click by hand, add ?slow=1 to the address, then click Eevee and Gholdengo about 1 s apart.
  • Other options: fixed.html?cancel=1 (cancel old requests), ?fail=species (a request fails).
  • Open DevTools → Network to see the requests, and the Race view under the card to see what the page did with each answer.
